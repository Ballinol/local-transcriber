# Local Transcriber

Локальный транскрибатор видео/аудио в текст. **Бесплатно, офлайн, без лимита длины.**
На базе [faster-whisper](https://github.com/SYSTRAN/faster-whisper). Опционально — **разбивка по спикерам** (кто говорит).

- Форматы: `mp4, mkv, webm, mov, mp3, wav, m4a, ...` (декод через PyAV, отдельный ffmpeg не нужен).
- Качество: пунктуация, заглавные буквы, корректные термины (Kubernetes, GitLab CI, Terraform…).
- Скорость: на NVIDIA GPU ~x14 быстрее реального времени (46 мин видео ≈ 3–4 мин на `large-v3-turbo`). На CPU медленнее, но работает.

## Установка

### 1. Python
Поставь Python 3.10+ с [python.org](https://www.python.org/downloads/).
На Windows при установке **обязательно** отметь галочку **«Add Python to PATH»**.

### 2. Скачай проект
«Code → Download ZIP» на GitHub и распакуй (или `git clone`).

### 3. Двойной клик `setup.bat`
Создаст окружение и поставит библиотеки для транскрипции (несколько минут).

### 4. (Опционально) `setup_diarize.bat` — для разбивки по спикерам
Ставит дополнительные пакеты (speechbrain, torch). Нужно только если хочешь видеть, кто говорит.

> **GPU-ускорение (по желанию):** после `setup_diarize.bat` можно переустановить torch под CUDA:
> ```
> .venv\Scripts\python.exe -m pip uninstall torch torchaudio -y
> .venv\Scripts\python.exe -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu126
> ```

*(Mac/Linux: вместо .bat создай venv вручную — `python -m venv .venv && .venv/bin/pip install -r requirements.txt`.)*

## Использование

### Просто текст — перетащи файл на `transcribe.bat`
Рядом с исходным файлом появится `<имя>.txt`. Совсем без команд.

Или из командной строки:
```
.venv\Scripts\python.exe transcribe_file.py "видео.mp4"
```
Опции:
- `--srt` — дополнительно сохранить субтитры `.srt` с таймкодами
- `--lang ru` — зафиксировать язык (по умолчанию автоопределение)
- `--model` — по умолчанию `large-v3-turbo` (быстрый, даёт полный текст). Точнее по терминам, но в ~5 раз медленнее и иногда «глотает» вступление: `large-v3`. Для слабых машин: `medium`/`small`
- `--device cpu|cuda` — принудительно CPU или GPU
- `--chunk-min N` — длинные файлы (1ч+) автоматически бьются на куски по N мин (по умолчанию 20) с прогрессом по чанкам. Без этого VAD-проход по многочасовому аудио может зависнуть.

### С разбивкой по спикерам
```
.venv\Scripts\python.exe diarize_transcribe.py "видео.mp4" --speakers 3
```
Создаёт `<имя>.speakers.txt` с репликами вида `Спикер 1: ...`.
- **`--speakers N`** — сколько человек говорит. **Указывай явно** — авто-режим (`--speakers 0`) часто дробит одного человека на нескольких.
- Имена вместо «Спикер N» — просто автозамена в готовом тексте (`Спикер 1` → `Иван`).

## Как это работает

- **Текст:** faster-whisper (`large-v3-turbo`). Для пунктуации/заглавных и правильных терминов подаётся `initial_prompt` + `hotwords` (см. верх `transcribe_file.py` — там можно добавить свои термины под свою тематику).
- **Спикеры:** голосовые эмбеддинги [speechbrain ECAPA](https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb) + агломеративная кластеризация. Всё локально, **без HuggingFace-токена**.

## Если что-то не так

- **`Python not found`** — не поставлена галочка «Add Python to PATH». Переустанови Python с ней.
- **Идёт на CPU, хотя есть NVIDIA GPU** — для GPU faster-whisper нужны CUDA-библиотеки (CUDA 12 + cuDNN 9). Проще всего доставить их так:
  ```
  .venv\Scripts\python.exe -m pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
  ```
  Скрипт сам пробует GPU и, если тот недоступен, **автоматически переключается на CPU** — упасть с ошибкой CUDA он не должен. На CPU тоже работает, просто медленнее (можно взять `--model medium`/`small`).
- **Диаризация нашла слишком много спикеров** — задай точное число: `--speakers N`.
- **`WinError 1314` (symlink)** — уже обработано в коде (speechbrain переключён на копирование). Если всплывёт в другом месте — включи «Режим разработчика» в Windows.
